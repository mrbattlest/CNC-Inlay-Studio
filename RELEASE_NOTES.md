- Added **20° V-bit** options (1/8" and 1/4" shank) to the My Bits
  catalog. The 20° angle is the sharpest in the lineup — useful for
  very fine-detail inlay where you want the V-walls to stay narrow:
  for a given pocket depth, a 20° bit's lateral reach (L = depth ×
  tan(10°) ≈ 0.18 × depth) is smaller than a 30° bit's (≈ 0.27 ×
  depth), so it can be used on designs with thinner features
  without erasing them. V-bit angle lineup is now 20° / 30° / 45° /
  60° / 90° in both shank sizes.
